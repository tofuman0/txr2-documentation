# The Nameless One — Delivery lorry

**Port addition:** This traffic challenge and Class T purchase are features of the native port. The original game did not allow traffic vehicles to be bought.

![Native port view of traffic model 136]({{ "/assets/cars/car-136.png" | relative_url }})

*Representative native port model view; the encountered traffic style may differ.*

## Challenge details

| Detail | Information |
| --- | --- |
| Traffic model ID | 136 |
| Vehicle | [FV — Delivery lorry]({{ "/cars/136.html" | relative_url }}) |
| Driver name | The Nameless One |
| Availability | Quest Keep Garage playthrough |
| Vehicle requirement | Defeat all seven other traffic models first. Drive a delivery lorry, roadworks lorry or tanker when challenging this model. |
| Challenge | Flash the headlights when an eligible traffic vehicle is in range. |
| Unlock | Win the battle to add this vehicle to the Class T dealer for 100,000 CP. |
| Win reward | 100 CP base plus remaining-SP and distance components. |
| Loss or draw | No CP is deducted and no new model is unlocked. |

See the linked car page for its specifications, part prices and calculated tuning effects. The game also applies proximity, alignment, speed and state checks before it accepts a challenge.
