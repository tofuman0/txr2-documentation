Engine and muffler torque-curve percentages and axle mass changes use the source tuning rows, with the other part at Normal and tuning settings neutral. The engine’s RPM shift changes the curve as well, so the percentage is not necessarily the change in peak horsepower. Boost-setting coefficients are source values; their effect depends on the selected setting.

Transmission ratios are source multipliers for the six ratio slots, including any slots not used by the original gearbox; the port applies the source fallback rules when a ratio is absent. Brake changes are source coefficient deltas, not a claimed percentage or stopping-distance measurement. Fields with unresolved meanings retain their source offsets.

Part effects compare one fitted variant with all other parts at Normal and settings neutral, using the port’s source-recovered tuning calculation. Grip values are changes to the initial front and rear grip coefficients; grip changes dynamically during driving. The downforce column reports changes to the front and rear aerodynamic coefficients, not a direct force or percentage; their effect depends on speed and the game’s sign conventions. Values are rounded. These calculations have not yet been compared against every original-game configuration.

Peak HP values are calculated with that part fitted alone against a calculated stock baseline; they can change with other parts and tuning settings.

Additional coefficient and dimension changes are relative to the same single-part stock baseline. Positive and negative damping refer to suspension velocity direction; the source does not label these values as a simple grip percentage.

Fields shown by hexadecimal offset are named by their source record position; their numeric changes are calculated by the port from the selected part.

Shop priority is the highest source priority among defeated rivals in the current or retained defeat set selected by the game. Persistent unlock bits are the source bank flags. Class T’s delivery-lorry override is a port addition; the table distinguishes stock/compatibility rules from the calculated performance of a part.
