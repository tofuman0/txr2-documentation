## Appearance

This team uses [appearance pool 4]({{ "/rival-appearance-pools.html#pool-4" | relative_url }}). The pool includes roads that also contain the 13-gochi starting point; individual rivals may be placed elsewhere.

This team is included in the source’s regular-team roster before the current Quest period records a defeat of the first stage boss. Pool activation and selection still determine whether a member appears during an outing.

The [leader]({{ "/rivals/171.html" | relative_url }}) can enter the candidate pool when not already defeated or present and either previously encountered or all other team members have been defeated. The source also allows the leader when exactly one branch member has been defeated and the team contains non-ordinary members.

For undefeated branch members, the selector waits until all ordinary members have been defeated. It then uses their encounter flags to choose branch kinds: kind 2 if none has an encounter flag; otherwise kind 1 plus kind 9 if all have encounter flags, or kind 8 if only some do. Only kinds actually present on this team can be selected. Previously defeated members are handled in a separate repeat-encounter bucket.
